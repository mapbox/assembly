Typography

Font styles, sizes, and utilities.

There are two ways to style text with Assembly: by applying utility classes to every element, or by creating prose sections. All typographic styles can be applied individually with classes that have a .txt- prefix. Alternatively, prose sections can be used to apply sensible default styling for all the semantic elements they contain.

Layout

Define the size, shape, and content flow of your markup.

Grid

Assembly uses a 12-column CSS Grid with optional gutters.

.grid.col

Grids require at minimum two elements: A parent with the class grid and a child with the class col. A col spans the full row unless you add a w-1/12 to w-11/12 fraction class, which sets how many of the 12 columns it spans. Offset a col that has a width class with an ml-1/12 to ml-11/12 fraction class; other left and right margins on col are ignored inside a grid. The grid class includes *-mm, *-ml, and *-mxl variations to target screen sizes.

Align columns with the flex--*-cross flexbox classes.

Dark mode

Prefix any class with dark: to apply it only in dark mode, which follows the user's system color scheme unless the page overrides it. Pair it with the light class it replaces. dark: classes are only available in on-demand builds; the CDN stylesheet doesn't include them.

Set data-theme="dark" or data-theme="light" on <html> to override the system setting. Remove the attribute to follow it again. Try it with this toggle, which sets data-theme on this page:

A toggle only needs to set the attribute. Set color-scheme too so native controls and scrollbars match:

js
function setTheme(theme) {
  const root = document.documentElement;
  if (theme === 'system') root.removeAttribute('data-theme');
  else root.setAttribute('data-theme', theme);
  root.style.colorScheme = theme === 'system' ? 'light dark' : theme;
}

dark: works with component classes and their hover and active states, and combines with media query suffixes: dark:block-mm applies block on medium screens and up in dark mode.

Icons

Assembly uses an SVG icon sprite. To load the sprite, you must must include assembly.js on your page.

Please read the Icons page to learn more about the available icons and the Javascript API section of the home page to learn how to use them.

.icon

The icon class must be appled to an <svg> element. Inside the <svg>, insert a <use> element whose xlink:href attribute points to an icon loaded by assembly.js. All icons are referenced by the string #icon-{name}. By default, icons inherit size from their calculated text size. Change the size of icons by applying w{size} and h{size} classes to the svg.

Be aware that icons are block-level.

Buttons

Although the btn class will apply button styling to any element, you should typically apply it to the <button> element. Not a <div> or <span> with a click handler, and not an <a> without an href attribute. <button> is semantically appropriate for anything with a click handler that changes the page dynamically. <button>s receive focus, handle keyboard events, can be disabled, and are fully accessible.

For actual links, you should usually use an <a> with the link class.

.btn

Apply a button style. To change the background color of a button, use a btn--{color} modifier (*-deep and *-dark colors are not available). Buttons have white text unless combined with a color-* class. Buttons have fully rounded corners unless combined with a round-* class.

<button class='btn'>Default</button>
<button class='btn btn--red'>Color</button>
<button class='btn btn--green color-yellow'>More colors</button>
<button class='btn round'>Less rounded</button>
<div class='px6 py6 bg-blue inline-block'>
  <button class='btn btn--white color-blue'>Reverse</button>
</div>
.btn--stroke

Modify a button so its text and borders are colored and its background transparent. The border color and text color will always match. To change the text and border color, use a btn--{color} modifier (*-deep colors are not available).

<button class='btn btn--stroke'>Default</button>
<button class='btn btn--stroke btn--red'>Color</button>
<button class='btn btn--stroke round'>Less rounded</button>
<div class='px6 py6 bg-blue inline-block'>
  <button class='btn btn--stroke btn--white'>Reverse</button>
</div>
.btn--s

Make a button small.

<button class='btn btn--s'>Small</button>
.btn.is-active.btn--stroke.is-active

Apply a darker active state to buttons by adding the is-active class.

<button class='btn is-active'>Active</button>
<button class='btn btn--red is-active'>Red and active</button>
<button class='btn btn--stroke is-active'>Active</button>
<button class='btn btn--stroke btn--red is-active'>Red and active</button>
.btn:disabled

When a button has the disabled attribute, it will be styled accordingly.

<button disabled class='btn'>Disabled button</button>
.btn--pill-stroke

Create pill button groups. Pill groups must be wrapped in a inline-flex container. Every button in a pill group must have

  • a btn class
  • any btn--* modifiers you want (e.g. btn--stroke)
  • a btn--pill or btn--pill-stroke modifier. Use the btn--pill-stroke modifier if the buttons in the pill group are mostly stroke buttons (though active buttons can be non-stroke, if you like that)
  • a btn--pill-* modifier specifying its position (e.g. btn--pill-hc)

For horizontal pills, use

  • inline-flex on the container
  • btn btn--pill(-stroke) btn--pill-hc (center)
  • btn btn--pill(-stroke) btn--pill-hl (left)
  • btn btn--pill(-stroke) btn--pill-hr (right)

For vertical pills, use

  • inline-flex flex--column on the container
  • btn btn--pill(-stroke) btn--pill-vc (center)
  • btn btn--pill(-stroke) btn--pill-vt (top)
  • btn btn--pill(-stroke) btn--pill-vb (bottom)

Pill buttons can be modified and themed in the same ways as regular buttons.

<div class="inline-flex">
  <button class="btn btn--pill btn--pill-hl">Left</button>
  <button class="btn btn--pill btn--pill-hc">Center</button>
  <button class="btn btn--pill btn--pill-hr">Right</button>
</div>
<div class="inline-flex flex--column">
  <button class="btn btn--stroke btn--pill-stroke btn--pill-vt">Top</button>
  <button class="btn btn--pill-stroke btn--pill-vc is-active">Center</button>
  <button class="btn btn--stroke btn--pill-stroke btn--pill-vb">Bottom</button>
</div>

Forms

Styles for HTML5 input and textarea elements. All form elements fit into Assembly's 6px baseline grid.

Inputs & textareas

The input class styles input types text, password, email, datetime, search, tel, url, and number. The textarea class styles the <textarea> element.

Both form elements fill the width of their container, by default. You should adjust the widths of inputs and textareas by adding w* width classes or controlling the widths of their containers, e.g. with grid classes.

Toggle group

The toggle group component styles a set of <input type=radio'> elements. The markup must fit the following pattern:

  • A wrapping <div> around all your radio options with the class toggle-group.
  • For each radio option, a wrapping <label> with the class toggle-container.
  • For each radio option, an <input type='radio'>.
  • For each radio option, a <div> with the class toggle.
.toggle-group.toggle-container.toggle

Style a toggle group. Change the inactive toggle text color and the active toggle background color with a toggle--{color} modifier (*-dark colors are not available). Change the active label color with a toggle--active-{color} modifier (*-dark colors are not available). Change the group background color by adding a bg-{color} class to the toggle-group element.

<div class='toggle-group mr18'>
  <label class='toggle-container'>
    <input checked name='toggle-1' type='radio' />
    <div class='toggle'>cat</div>
  </label>
  <label class='toggle-container'>
    <input name='toggle-1' type='radio' />
    <div class='toggle'>dog</div>
  </label>
</div>
<div class='toggle-group bg-blue-faint'>
  <label class='toggle-container'>
    <input checked name='toggle-2' type='radio' />
    <div class='toggle toggle--blue'>cat</div>
  </label>
  <label class='toggle-container'>
    <input name='toggle-2' type='radio' />
    <div class='toggle toggle--blue'>dog</div>
  </label>
</div>

Toggle labels don't wrap. To fit a group with long labels to its container, add wmax-full to the toggle-group, then either:

  • Truncate: add wmin0 to the long label's toggle-container and txt-truncate align-center py3 to its toggle. Add flex-child-no-shrink to other toggle-container elements to keep them whole.
  • Wrap: add flex to each toggle-container and txt-wrap align-center h-auto hmin24 py3 to each toggle. Use hmin18 with toggle--s or hmin36 with toggle--l.

      <div class='toggle'>dog</div>
    </label>
  </div>

<div class='w240'>
